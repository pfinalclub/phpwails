# Getting Started

1. Run `phpwails doctor` to inspect PHP, JSON/PHAR, Node.js and npm prerequisites.
2. Run `phpwails init hello --template=vanilla`.
3. Run `phpwails dev` from the generated project.

The current alpha validates the project and CLI flow. Native WebView hosting and the generated binding bridge are the next implementation slice; a development machine without a compiled native host receives an explicit diagnostic rather than a blank window.
