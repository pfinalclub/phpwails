# PhpWails development dependencies

- PHP 8.2+ for the application compatibility baseline.
- CMake 3.20+ and a C++17 compiler for native development.
- Node.js LTS and npm for frontend templates.
- Platform WebView runtime: WebView2, WKWebView, or WebKitGTK according to the support matrix.
- Release builds use a digest-pinned static-php-cli runtime; never download `latest` during application launch.
